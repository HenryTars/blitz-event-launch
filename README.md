# BliTz Launch

A luxury book launch and poetry event management platform built with Next.js, TypeScript, TailwindCSS, Framer Motion, Supabase, Prisma, and modern UI architecture.

## Phase 1: Foundation

- Setup project architecture
- Configure UI system and theme
- Create reusable global styles and animation-ready landing shell
- Prepare database schema for event, guest, and invitation models

## Architecture Vision

The platform is designed to support multiple authors and events with:

- secure event and guest management
- personalized invitation links
- RSVP workflow and preorder tracking
- admin analytics dashboard
- responsive cinematic landing pages
